# Models

CC0 (public domain) from [Kenney](https://kenney.nl), the Blaster Kit 2.1 (`https://kenney.nl/assets/blaster-kit`), GLB format. Each GLB reads its colors from the shared palette image `Textures/colormap.png` (from the same kit), so that file must sit beside them. The three weapons pick from these; see `app/play/view.js` for which is which.
